# معرض الطيب للمعدات الثقيلة — Al Tayeb Heavy Equipment

الموقع الرسمي ومنصة العرض الرقمية المتكاملة لمعرض الطيب للمعدات الثقيلة (لوادر، حفارات، بلدوزرات، أوناش، كلاركات، ومعدات الطرق) مع لوحة تحكم ديناميكية شاملة لإدارة كافة أقسام ومحتويات الموقع بدون أي تعديل برمجي.

---

## المميزات والمواصفات المنجزة (Key Features)

### 1. الهوية البصرية والتصميم الصناعي الراقي (Visual Identity & Industrial Design)
- **Palette:** لوحة ألوان داكنة صناعية مستوحاة من كبرى الماركات العالمية (CAT, Komatsu, Volvo CE):
  - أسود داكن فاحم: `#080808`
  - فحم داكن للبطاقات: `#151515`
  - أصفر صناعي أساسي: `#F5C400`
  - أصفر دافئ للأزرار: `#FFD429`
  - نصوص وأرقام بيضاء مع درجات رمادية ناعمة للبيانات الثانوية.
- **Glassmorphism:** تأثيرات زجاجية راقية مع خلفيات صفراء شفافة لعناوين الأقسام.
- **Micro-interactions:** حركات وتحولات ناعمة، تأثيرات تكبير للصور عند التحويم، وحواف مضيئة بلمسات صفراء.

### 2. الأنيميشن السينمائي الافتتاحي (Cinematic Intro Animation)
- يبدأ الموقع بشاشة سوداء بالكامل.
- يدخل لودر أصفر واقعي ثلاثي الأبعاد من يمين الشاشة متجهاً إلى اليسار وهو يدفع الرمال أمامه.
- محاكاة فيزيائية حية لذرات الرمال والدخان والغبار المتصاعد من باكت اللودر.
- انبثاق سينمائي لاسم المعرض **معرض الطيب** وشعار المعرض الرسمي من خلال طبقات الغبار.
- إمكانية التخطي الفوري (**Skip Intro**).
- حفظ جلسة الزائر (`sessionStorage`) لتفادي تكرار الأنيميشن في كل تنقل داخلي.
- دعم إعدادات تقليل الحركة (`prefers-reduced-motion`) وإمكانية التفعيل/التعطيل من لوحة التحكم.

### 3. الهيدر وشريط التنقل الذكي (Header & Navigation)
- هيدر أسود زجاجي ثابت (`sticky navigation`) يتكيف بنعومة مع التمرير.
- **أقصى اليسار:** زر تبديل اللغة الفوري (العربية / English).
- **بجواره مباشرة:** شعار المعرض واسم العلامة التجارية.
- **أقصى اليمين:** أيقونة القائمة الهامبرغر الفاخرة (3 خطوط أفقية).
- درج تنقل جانبي يفتح بنعومة ويحتوي على كافة الصفحات:
  1. الرئيسية (Home)
  2. جميع المعدات (All Equipment)
  3. فئات المعدات (Equipment Categories)
  4. اتصل بنا (Contact Us)
  5. موقع المعرض والفروع (Showroom Location)
  6. محتاج معدة غير متوفرة؟ (Looking for Equipment Not Available?)
  7. أبلغني عند التوفر (Notify Me When Available)

### 4. سلايدر البانر التلقائي (3.5s Cinematic Hero Slider)
- تبديل تلقائي للصور كل 3.5 ثوانٍ بحركات تلاشٍ سينمائية وانتقالات انسيابية.
- بطاقات نصوص زجاجية متقدمة تضمن وضوحاً كاملاً للقراءة على الهواتف والشاشات الكبيرة.
- تحكم يدوي بالأسهم والمؤشرات النقطية مع إيقاف مؤقت للتبديل عند تحويم الماوس.
- قابل للإدارة والإضافة الكاملة من لوحة التحكم (إضافة صور مخصصة للهواتف وللسطح المكتبي).

### 5. الفئات وفهرس المعدات (Dynamic Categories & Catalog)
- بطاقات الفئات بتصميم صناعي جذاب وخلفيات زجاجية صفراء شفافة.
- فهرس متكامل للمعدات مع تصفية سريعة حسب الفئة، الحالة (متوفر، محجوز، مباع)، وشريط بحث نصي ذكي.
- بطاقات المعدات تدعم عرض سلايدشو تلقائي للصور المتعددة، الماركة، الموديل، سنة الصنع، والسعر المنسق أو خيار **اتصل للسعر**.

### 6. صفحة تفاصيل المعدة الفردية (Equipment Details Page)
- رابط مستقل وخاص لكل معدة (SEO-friendly URL).
- معرض صور تفاعلي متعدد مع شريط مصغرات وإمكانية العرض بملء الشاشة (**Fullscreen Lightbox**).
- جدول مواصفات فنية تفصيلي وواضح.
- **الزران الإلزاميان للتواصل:**
  1. **اطلب الآن عبر واتساب:** يفتح محادثة واتساب مع رسالة جاهزة تلقائياً تحتوي على اسم وموديل المعدة.
  2. **اتصال هاتفي مباشر:** يفتح مشغل الهاتف بالرقم الرسمي المسجل بالمعرض.

### 7. نظام طلب المعدات المخصصة (Custom Equipment Sourcing System)
- قسم مخصص للعملاء الذين يبحثون عن معدة غير مدرجة حالياً.
- نموذج احترافي مع التحقق من صحة البيانات (الاسم، الهاتف، نوع المعدة، الماركة، الموديل، المواصفات، الملاحظات).
- حفظ حقيقي في قاعدة البيانات مع توليد **رقم مرجعي فريد تلقائياً** (مثل `REQ-M1ABC-9X2`).
- إمكانية متابعة وإدارة الطلبات وتحديث حالاتها من لوحة التحكم وإضافة ملاحظات داخلية لفريق المبيعات.

### 8. فروع المعرض وروابط التواصل (Branches & Contact)
- دعم مرن لإضافة عدد غير محدود من الفروع مع العناوين، أرقام الهواتف، وروابط خرائط جوجل.
- أيقونات منصات التواصل الاجتماعي القابلة للتخصيص من لوحة التحكم.

### 9. لوحة تحكم الإدارة الشاملة (Admin Dashboard)
- تسجيل دخول آمن ومحمي بجلسات JWT وتشفير كلمات المرور `bcrypt`.
- إحصائيات عامة فورية (إجمالي المعدات، المتوفر، المباع، الفئات، الطلبات الجديدة).
- **إدارة المعدات:** إضافة وتعديل وحذف المعدات، رفع صور متعددة بالسحب والإفلات وتعيين صورة الغلاف، تخصيص الأسعار والمواصفات وتحديد المعدات المميزة.
- **إدارة الفئات:** إضافة وحذف الفئات ورفع صور الغلاف وترتيب الظهور.
- **إدارة البانرات:** إضافة سلايدات الهيرو وتغيير العناوين والصور.
- **إدارة الفروع:** إضافة فروع جديدة وعناوينها وروابط الخرائط.
- **إدارة روابط السوشيال ميديا:** ربط فيسبوك، انستغرام، تيك توك، يوتيوب، إلخ.
- **إدارة الطلبات:** تصفية الطلبات، تغيير الحالات، إضافة ملاحظات داخلية، والتواصل مع العميل مباشرة بضغطة زر.
- **إعدادات الموقع الديناميكية بالكامل:** تعديل اسم المعرض باللغتين، أرقام الهواتف والواتساب، الشعار، نصوص الهيرو والفوتر، وتفعيل/تعطيل الأنيميشن الافتتاحي.

- **رابط لوحة التحكم:** `http://localhost:3000/admin/login`
- **اسم المستخدم:** `admin`
- **كلمة المرور:** `admin123456`

*(يمكنك تغيير كلمة المرور أو إنشاء حسابات جديدة عبر قاعدة البيانات أو واجهة الإدارة)*

## التشغيل والتثبيت محلياً (Local Setup & Run)

1. **الانتقال لمجلد المشروع:**
   ```powershell
   cd "f:\الطيب\al-tayeb"
   ```

2. **تثبيت الحزم (إن لم تكن مثبتة):**
   ```powershell
   npm install
   ```

3. **تهيئة قاعدة البيانات وزرع البيانات التجريبية:**
   ```powershell
   node database/seed.js
   ```

4. **تشغيل خادم التطوير (Development Server):**
   ```powershell
   npm run dev
   ```

5. **أو بناء وتشغيل نسخة الإنتاج (Production Build):**
   ```powershell
   npm run build
   npm start
   ```

الموقع متاح افتراضياً على: `http://localhost:3000`

## الهيكل التقني وقاعدة البيانات (Technical Architecture)

- **Framework:** Next.js 14+ (App Router) مع TypeScript.
- **Styling:** Tailwind CSS مع نظام ألوان صناعي داكن وتأثيرات زجاجية.
- **Database:** SQLite عبر `better-sqlite3` بدون حاجة لتثبيت خوادم خارجية.
- **Storage:** حفظ الصور في `public/uploads/` مع توليد معرفات `uuid` فريدة وتخزين المسارات في قاعدة البيانات.
- **Security:** ملفات تعريف ارتباط `httpOnly` مع توكنات `JWT` مشفرة وخوارزمية `bcrypt` للتجزئة.
- **SEO:** خريطة موقع ديناميكية `sitemap.xml` وملف `robots.txt` وبيانات وصفية `Open Graph` لكل صفحة ومعدة.
